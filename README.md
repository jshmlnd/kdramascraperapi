# kdramascraperapi

Scraping API generated by **[@zjkm666/scraperapi](https://github.com/jshmlnd/zjkm666-package)**.

Source URL: `https://kisskh.do/`

## Quick start

```bash
npm install
npm run dev   # http://localhost:3000  (auto-restart on file changes)
# or
npm start
```

Optional for JS-rendered sites (SPA, lazy load):

```bash
npm install playwright
npx playwright install chromium
# then set renderJs: true in api.config.js per endpoint
```

## Endpoints

| Method | Path | What it does |
|---|---|---|
| GET | `/` | Lists all available endpoints + cache stats |
| GET | `/health` | Health check |
| GET | `/cache/stats` | Cache statistics |
| DELETE | `/cache` | Clear cache |
| GET | `/products` | Example GET – edit selector/fields in `api.config.js` |
| POST | `/search` | Example POST – POST `{ "query": "shoes" }` |

All scraping endpoints return:

```json
{
  "success": true,
  "source": "https://example.com/search?q=shoes",
  "count": 12,
  "data": [{ "title": "...", "price": "..." }],
  "tookMs": 342
}
```

Cached responses include `"cached": true` and header `X-Cache: HIT`.

## Customizing

Edit **`api.config.js`** – it's the single source of truth. No need to touch `server.js` for simple changes.

### Add a GET endpoint

```js
{
  method: 'GET',
  path: '/news',
  selector: 'article',
  fields: {
    headline: 'h2',
    url: 'a@href',
    summary: 'p',
    date: 'time@datetime | time',
  },
  // renderJs: true,   // JS-rendered?
  // cache: { ttl: 60 }, // override cache TTL
  // limit: 20,
}
```

### Add a POST endpoint (scrape using `req.body`)

```js
{
  method: 'POST',
  path: '/search',
  selector: '.result',
  fields: { title: 'h2', link: 'a@href' },
  buildUrl: (baseUrl, req) => {
    // req.body, req.query, req.params all available
    const q = req.body.query;
    const page = req.body.page || 1;
    return `${baseUrl}/search?q=${encodeURIComponent(q)}&page=${page}`;
  }
}
```

Field shorthand:

- `"h2"` → text content
- `"a@href"` → attribute
- `"a@href | text"` → fallback
- `{ selector: ".price", attr: "data-price" }`
- `{ selector: ".desc", html: true }`
- `(el, $) => $(el).find('a').data('id')` → custom function

### JS-rendered sites

If content loads via JavaScript (React, Vue, infinite scroll):

```js
{ path: '/dynamic', selector: '.card', renderJs: true, fields: {...} }
```

For wait strategies, add `fetchOpts`:

```js
{ renderJs: true, fetchOpts: { waitForSelector: '.card', delayMs: 1000 } }
```

### Cache

Global cache is `true` by default (TTL 300s). Toggle:

```js
// api.config.js
cache: { enabled: true, ttl: 300 }

// per-endpoint
{ path: '/live', cache: false }
{ path: '/daily', cache: { ttl: 86400 } }
```

Clear manually: `curl -X DELETE http://localhost:3000/cache`
